# Practical 4 — Perform Functions & Advanced Operators

> **Experiment No:** 4
> **Relevant CO:** CO3
> **Equipment/Instruments:** Personal Computer, MySQL

## Title

Perform Functions & Advanced Operators.

## Objectives

- Use aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`) to summarise table data.
- Use single-row string functions (`UPPER`, `LOWER`, `LENGTH`, `SUBSTRING`, `CONCAT`, etc.).
- Use numeric and date functions (`ROUND`, `CURDATE`, `NOW`, etc.).
- Group rows using the `GROUP BY` clause.
- Filter grouped results using the `HAVING` clause.

## Procedure

1. Start the database server and log in to the MySQL prompt with the correct user ID and password.
2. Run `schema.sql` once to create the shared `dbms_lab` database and sample data.
3. Execute the queries for questions 1–19 in order.

## Safety and Necessary Precautions

1. Make sure the database server is started.
2. Login with correct user ID and password in MySQL.
3. Verify column names in aggregate and grouping queries; only grouped or aggregated columns may appear in the select list.

## Question Groups

1. **Aggregate Functions** — Q1–Q6
2. **Single Row Functions** — Q7–Q12
3. **GROUP BY Clause** — Q13–Q17
4. **HAVING Clause** — Q18–Q19
