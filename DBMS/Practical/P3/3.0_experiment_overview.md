# Practical 3 — Displaying Data from Multiple Tables using JOIN Operations

> **Experiment No:** 3
> **Relevant CO:** CO3
> **Equipment/Instruments:** Personal Computer, MySQL

## Title

Displaying data from multiple tables using join operations.

## Objectives

- Retrieve combined data from two or more tables using `INNER JOIN`.
- Join tables across students, courses, departments, faculty, and enrollments.
- Use table aliases to keep multi-table queries readable.
- Use `LEFT JOIN` and `RIGHT JOIN` to retain unmatched rows (outer joins).
- Use a `SELF JOIN` to compare rows within the same table.

## Procedure

1. Start the database server and log in to the MySQL prompt with the correct user ID and password.
2. Run `schema.sql` once to create the shared `dbms_lab` database and sample data.
3. Execute the queries for questions 1–20 in order.

## Safety and Necessary Precautions

1. Make sure the database server is started.
2. Login with correct user ID and password in MySQL.
3. Verify join conditions carefully to avoid accidental Cartesian products.

## Question Groups

1. **INNER JOIN** — Q1–Q15
2. **Other JOINs (LEFT / RIGHT / SELF)** — Q16–Q20
