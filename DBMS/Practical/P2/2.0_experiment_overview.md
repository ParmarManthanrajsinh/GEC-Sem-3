# Practical 2 — Data Constraints and ALTER TABLE

> **Experiment No:** 2
> **Relevant CO:** CO3
> **Equipment/Instruments:** Personal Computer, MySQL

## Title

Implement Data Constraints: Add primary key, foreign key, unique key, and check
constraints, define and remove integrity constraints using the `ALTER TABLE`
command.

## Objectives

- Use the `UPDATE` statement to modify existing rows.
- Use the `ALTER TABLE` command to add, modify, and drop columns.
- Apply defaults and `NOT NULL` constraints while altering a table.
- Define primary key and foreign key constraints on a table.
- Use `DELETE`, `TRUNCATE`, and `DROP` to remove data and objects.

## Procedure

1. Start the database server and log in to the MySQL prompt with the correct user ID and password.
2. Run `schema.sql` once to create the shared `dbms_lab` database and sample data.
3. Execute the queries for questions 1–24 in order.

## Safety and Necessary Precautions

1. Make sure the database server is started.
2. Login with correct user ID and password in MySQL.
3. Back up the database before running bulk `UPDATE`, `DELETE`, `TRUNCATE`, or `DROP` commands.
