# Applications of Hashing

Hashing maps a key to an index in a hash table using a hash function, giving
average-case O(1) insertion, deletion and lookup. Common applications:

## 1. Database Indexing
- Hash indexes locate records directly without scanning the table.
- Used for equality queries such as `WHERE id = 101`.

## 2. Symbol Tables in Compilers
- Compilers store variable, function and keyword names in a hash table.
- Enables quick lookup during parsing and semantic analysis.

## 3. Password Storage
- Systems store hashed passwords instead of plain text.
- Salted hashes protect credentials even if the database is leaked.

## 4. Caches and Key-Value Stores
- In-memory caches (Redis, Memcached) use hashing to find keys fast.
- Web browsers cache URLs using hash tables.

## 5. File Systems and Storage
- File systems use hashing to locate files in directories.
- Content-addressed storage (e.g. Git) identifies objects by hash.

## 6. Network Routing and Load Balancing
- Routers use hash tables for forwarding and flow lookup.
- Load balancers hash client IPs to distribute requests across servers.

## 7. Data Deduplication and Integrity
- Checksums and cryptographic hashes detect duplicate or corrupted data.
- Hash values verify file integrity after transfer.

## 8. Spell Checkers and Dictionaries
- Word lists are stored in hash sets for fast membership testing.
- Autocorrect and search suggestions rely on hashed n-grams.

## Summary

| Domain | Use of Hashing |
|---|---|
| Databases | Fast record lookup, hash indexes |
| Compilers | Symbol table management |
| Security | Password hashing, integrity checks |
| Systems | Caches, file systems, routing |
| Applications | Dictionaries, spell check, deduplication |
