# Applications of Linked List

A linked list stores data in nodes connected by pointers. Unlike an array, it grows dynamically and allows fast insertion/deletion without shifting elements.

## 1. Dynamic Memory Management
- Operating system keeps a free list of memory blocks as a linked list
- Adjacent free blocks are linked together for allocation

## 2. Stack and Queue Implementation
- Stack (LIFO) and Queue (FIFO) can be built using a singly linked list
- Avoids the fixed-size limitation of array based stacks/queues

## 3. Hash Tables (Chaining)
- Collisions are resolved by chaining entries in a linked list
- Each bucket holds a linked list of keys that hash to the same index

## 4. Graph and Tree Representation
- Adjacency list of a graph stores neighbours of each vertex in a linked list
- Saves memory compared to an adjacency matrix for sparse graphs

## 5. Polynomial Arithmetic
- Polynomials are stored as a linked list of (coefficient, exponent) nodes
- Used for addition, subtraction and multiplication of large polynomials

## 6. Music and Video Playlists
- Circular linked list is used to loop a playlist continuously
- Next/Previous track simply follows the next/prev pointer

## 7. Round Robin Scheduling
- CPU scheduling uses a circular linked list of processes
- Each process gets a fixed time slice and control returns to the first process

## 8. Image Viewer / Slideshow
- Photos are linked so that the last image points back to the first (circular)
- Navigate forward and backward without reaching an end

## 9. Undo/Redo and Browser History
- Doubly linked list maintains forward and backward navigation
- Each action links to the previous and next action

## 10. Symbol Table in Compilers
- Compilers keep identifiers in a linked list during parsing
- New symbols are inserted as they are encountered

## Summary

| Application | Type of Linked List |
| --- | --- |
| Free memory blocks | Singly / Doubly |
| Stack, Queue | Singly |
| Hash chaining | Singly |
| Graph adjacency list | Singly |
| Playlist, Round Robin | Circular |
| Browser history | Doubly |
| Polynomial arithmetic | Singly |
