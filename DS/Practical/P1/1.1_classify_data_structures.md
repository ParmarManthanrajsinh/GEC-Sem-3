# Classification of Data Structures

## 1. Based on Memory Allocation

### Primitive Data Structures
- Store single values directly
- Examples: int, float, char, double

### Non-Primitive Data Structures
- Store collection of data
- Examples: Array, Linked List, Stack, Queue, Tree, Graph

---

## 2. Based on Organization

### Linear Data Structures
- Elements are arranged sequentially, one after another
- Each element has a single predecessor and successor (except first and last)
- Examples: Array, Stack, Queue, Linked List

### Non-Linear Data Structures
- Elements are arranged in hierarchical or interconnected manner
- An element can be connected to multiple elements
- Examples: Tree, Graph
