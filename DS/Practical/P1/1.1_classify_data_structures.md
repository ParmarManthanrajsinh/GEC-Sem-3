# Classification of Data Structures

Data structures are primarily classified into two main categories: Primitive Data Structures and Non-Primitive Data Structures. Non-primitive data structures are further divided based on how the data elements are organized and managed in memory.

## 1. Primitive Data Structures

These are the most fundamental data structures available directly within a programming language. They operate at the machine instruction level and store a single value.

- **Integer**: (e.g., `42`, `-7`).
- **Float / Double**: (e.g., `3.14`).
- **Character**: (e.g., `'A'`, `'$'`).
- **Boolean**: (e.g., `true`, `false`).
- **Pointer**: (e.g., `0x02f0`).
