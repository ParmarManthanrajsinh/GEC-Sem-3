# Applications of Stack Data Structure

## 1. Function Call Management
- Every function call is pushed onto the call stack
- When function returns, it is popped from the stack
- Recursion uses the call stack internally

## 2. Expression Evaluation and Conversion
- Converting infix to postfix/prefix expressions
- Evaluating postfix and prefix expressions
- Checking balanced parentheses/brackets

## 3. Undo/Redo Operations
- Text editors use stack for undo feature
- Each action is pushed onto the stack
- Undo pops the last action

## 4. Browser History
- Back button maintains a stack of visited pages
- Going back pops the current page
- Forward uses another stack

## 5. Syntax Parsing
- Compilers use stack for syntax analysis
- Matching opening and closing symbols like {}, [], ()

## 6. Memory Management
- Local variables are stored in stack memory
- Stack memory follows LIFO order automatically

## 7. Tower of Hanoi
- Classic recursive problem solved using stack (recursion stack)

## 8. DFS (Depth First Search)
- Graph traversal algorithm uses stack to track visited nodes
