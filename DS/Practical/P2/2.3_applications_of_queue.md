## Practical 2.3: Widely Used Applications of Queue Data Structure

### Applications of Queue

1. **CPU Scheduling & Disk Scheduling**
   - Operating systems use queues for process scheduling (FCFS, round-robin) and disk arm scheduling algorithms.

2. **Printer Spooling**
   - Print jobs are queued in order and processed one by one by the printer (FIFO order).

3. **BFS (Breadth-First Search) in Graphs**
   - BFS traversal of graphs and trees uses a queue to visit nodes level by level.

4. **Interrupt Handling in Real-Time Systems**
   - Hardware interrupts are queued and handled in the order they arrive.

5. **Buffering in I/O Operations**
   - Input/output buffers (e.g., keyboard buffer, streaming data buffer) use queues to handle data temporarily.

6. **Customer Service / Call Center Systems**
   - Incoming calls or service requests are handled in the order received using a queue.

7. **Traffic Management**
   - Vehicles at toll booths, traffic signals follow a queue pattern.

8. **Version Control Systems (Git)**
   - Git uses a queue (staging area) to track changes before committing.

9. **Message Queues in Networking**
   - Routers and switches use packet queues to manage network traffic and avoid congestion.

10. **Sliding Window Problems**
    - Used in algorithms like the maximum of all subarrays of size k.

### Key Principle
All queue applications rely on the **FIFO (First In, First Out)** property — the first element added is the first one to be processed.
