## 🚀 How to Use

- Browse each subject folder to find the syllabus and notes.
- Open the class timetable for the current schedule.
- Feel free to add your own notes, previous year papers, or reference material to the relevant subject folder.

### Adding New Material

1. Place the file inside the matching subject folder (e.g., `DBMS/`).
2. If it's a **syllabus**, name it with the subject code (e.g., `BE03000091.pdf`).
3. For new subjects, create a new folder and update the table in this README.

---

## 🧠 Tips

- Keep file names descriptive and consistent (e.g., `Unit-2 Stacks and Queues.pdf`).
- Use PDF format for easy viewing on any device.
- Commit small, well-named files so the history stays clean.
